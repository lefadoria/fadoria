# Fadoria — site vitrine

Site one-page responsive pour des cours de chant à domicile.

## Fichiers
- `index.html` : structure du site
- `styles.css` : design et responsive
- `script.js` : menu mobile + formulaire
- `assets/fadoria-logo.jpg` : image/logo fourni

## À personnaliser avant mise en ligne
1. Remplacer `bonjour@fadoria.fr` dans `index.html` par votre vraie adresse e-mail.
2. Connecter le formulaire de rendez-vous à votre outil préféré (Calendly, Google Calendar, formulaire Formspree, etc.).
3. Adapter les textes, tarifs, zone géographique et coordonnées.
4. Ajouter éventuellement une photo de vous et une photo d'ambiance.

Le design reprend l'esprit de l'image fournie : blanc/ivoire, bleu profond, bleu canard, touches dorées et terracotta, avec une esthétique musicale élégante.
